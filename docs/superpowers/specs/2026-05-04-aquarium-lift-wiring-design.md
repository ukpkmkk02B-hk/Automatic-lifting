# 鱼缸框篮自动升降控制装置接线设计

日期：2026-05-04
状态：用户确认的暂定硬件接线方案

## 目标

本项目使用 STM32F103C8T6 控制鱼缸内框篮上下移动，使框篮内多鳍鱼实际可活动水深保持设定值，或按照设定曲线随时间缓慢变浅。控制对象是框篮相对鱼缸水面的高度，不是整体鱼缸水位。

框篮最大行程为 100mm。两个贯穿式步进电机同步驱动框篮两侧，丝杆导程为 2mm，丝杆长度为 250mm。水深控制允许误差目标为 ±1mm。

系统由以下模块组成：

- 0.96 寸 OLED 显示屏
- 三颗 WF5805F 压力传感器小板
- UM244 二相步进电机驱动器
- 两个 42HSC1409-250NE2 贯穿式丝杆步进电机

- 24V 限位信号到 STM32 的光耦隔离输入电路

## 压力传感器方案

WF5805F 是绝对压力传感器，读数包含大气压。为达到 ±1mm 水深控制目标，系统使用三颗 WF5805F：

| 传感器 | 位置 | 作用 |
|---|---|---|
| `P_air` | 控制盒内，接触空气 | 大气压参考 |
| `P_tank` | 鱼缸底部固定位置 | 计算整体鱼缸水深并提供安全判断 |
| `P_basket` | 框篮底部，随框篮移动 | 计算框篮内实际可活动水深 |

水深计算使用压力差：

```text
basket_depth_mm = (P_basket - P_air) * 10.197
tank_depth_mm   = (P_tank   - P_air) * 10.197
```

其中压力单位为 hPa，`1 hPa` 约等于 `10.197 mmH2O`。

## WF5805F 两组 I2C 接线

不使用 I2C 多路复用器。三颗 WF5805F 分成两组 I2C：

| I2C 总线 | STM32 引脚 | 设备 | 地址选择 | I2C 7-bit 地址 |
|---|---|---|---|---|
| I2C-A | `PB8=SCL`, `PB9=SDA` | OLED | 固定 | OLED 常见地址 `0x3C`，现有代码使用写地址 `0x78` |
| I2C-A | `PB8=SCL`, `PB9=SDA` | `P_air` | `SDO/ADDR` 接 GND | `0x6C` |
| I2C-A | `PB8=SCL`, `PB9=SDA` | `P_tank` | `SDO/ADDR` 接 3.3V | `0x6D` |
| I2C-B | `PB6=SCL`, `PB7=SDA` | `P_basket` | `SDO/ADDR` 接 GND | `0x6C` |

每颗 WF5805F 小板接线：

| WF5805F 引脚 | 接法 |
|---|---|
| `VDD` | 3.3V |
| `GND` | GND |
| `SCL/SCLK` | 对应 I2C 总线 SCL |
| `SDA` | 对应 I2C 总线 SDA |
| `CSB` | 3.3V，固定 I2C 模式 |
| `SDO/ADDR` | 按地址接 GND 或 3.3V |
| `INT` | 暂不接，软件轮询读取 |
| `NC` | 不接 |

上拉电阻：

| 总线 | 上拉 |
|---|---|
| `PB8/PB9` | `SCL/SDA` 各 4.7k 上拉到 3.3V |
| `PB6/PB7` | `SCL/SDA` 各 4.7k 上拉到 3.3V |

每个传感器小板可预留 I2C 上拉焊盘，但同一总线上只焊一组 4.7k。若每块小板都必须焊上拉，建议使用 10k，避免并联后总上拉过强。

## WF5805F PCB 与防水封装要求

每块 WF5805F 小板必须包含：

- `VDD-GND` 旁路 100nF 电容，靠近芯片放置
- I2C 上拉电阻焊盘
- 四线接口：3.3V、GND、SCL、SDA
- 防水线缆应力释放
- 电路区域完全防水密封
- 压力敏感区域必须能接收到外部水压

封装必须避免把压力敏感结构完全刚性灌死。可采用柔性隔离膜、油腔或软胶膜等结构传递水压，同时防止水进入电路。空气参考传感器不下水，安装在控制盒内，保持与外界空气连通，避免盒内完全密封导致参考压力滞后。

## 步进电机与 UM244 驱动器

电机资料参数：

| 项目 | 数值 |
|---|---|
| 型号 | `42HSC1409-250NE2` |
| 步距角 | 1.8 度 |
| 额定电流 | 1.33A/相 |
| 额定电压 | 2.93V |
| 相电阻 | 2.2Ω |
| 相电感 | 3.5mH |
| 保持转矩 | ≥270mN.m |
| 丝杆导程 | 2mm |
| 标称步距 | 0.01mm/step |

UM244 供电：

| UM244 端子 | 接线 |
|---|---|
| `V+` | 24V 电源正 |
| `V-` | 24V 电源负 |
| `A+ A- B+ B-` | 接两个电机并联后的两相绕组 |

两个电机并联到同一个 UM244 驱动器输出。按资料线色，先按以下方式接线，并在低速低电流下确认方向：

| 电机线色 | 接线建议 |
|---|---|
| 红、绿 | 一相，接 `A+ / A-` |
| 黄、蓝 | 一相，接 `B+ / B-` |
| 两个电机 | 同色线并到同一个驱动器端子 |

若两个电机方向不一致，交换其中一个电机同一相的两根线，例如只交换该电机的 `A+ / A-`。

UM244 拨码建议：

| 项目 | 设置 |
|---|---|
| 运行电流 | 先设 2.5A：`SW1=ON`, `SW2=ON`, `SW3=OFF` |
| 细分/速度模式 | `SW4=OFF`，细分设置模式 |
| 细分 | 1600 pulse/rev：`SW5=OFF`, `SW6=OFF`, `SW7=ON`, `SW8=ON` |
| 位移换算 | 1600 pulse/rev ÷ 2mm = 800 pulse/mm |

若 2.5A 扭矩不足，可在确认温升和机械阻力正常后试 3.0A。不要按电源 5A 能力直接把驱动器电流拨到最大。

电机资料中的 `0.01mm/step` 对应 200 full-step/rev 时的整步位移。当前推荐 UM244 使用 1600 pulse/rev 细分，因此 1 个输入脉冲对应：

```text
1 pulse = 2mm / 1600 = 0.00125mm
0.01mm  = 8 pulse
1mm     = 800 pulse
```

## 自动打盹运动策略

自动模式不使用连续极低速运行。多鳍鱼幼鱼身体直径不到 10mm，连续移动或一次移动过大会造成不必要扰动。系统采用“打盹模式”：

1. 大部分时间电机处于静止保持状态。
2. 每隔固定时间唤醒一次运动控制。
3. 读取三颗压力传感器并检查四个限位器状态。
4. 若状态正常且当天仍有下降计划额度，以舒适、安全、低抖动的脉冲频率执行极小位移。
5. 位移完成后立即停止发送脉冲，保存累计进度，回到静止保持状态。

默认目标曲线暂定为框篮内实际水深每天变浅 `1mm/day`。按 1600 pulse/rev 细分计算，每天需要累计上升 `800 pulse`。

推荐自动打盹参数：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 每日变浅量 | `1mm/day` | 可后续通过菜单设置 |
| 自动细分 | `1600 pulse/rev` | 保持 UM244 细分，运动更平滑 |
| 每日总脉冲 | `800 pulse/day` | 对应 1mm |
| 精细打盹单位 | `1 pulse` | 单次位移 0.00125mm，约每 108 秒执行一次 |
| 稳妥打盹单位 | `8 pulse` | 单次位移 0.01mm，约每 14.4 分钟执行一次 |
| 默认原型模式 | `8 pulse/次` | 先验证机械是否真实响应；若运动过于可见，再切到 1 pulse/次 |
| 自动脉冲频率 | `20-50Hz` 起步 | 只在极短唤醒窗口内运行，不连续转动 |

自动模式优先采用计划位移累加，而不是根据传感器噪声频繁追调。压力传感器用于确认实际水深、校正长期误差和检测异常。若传感器显示实际水深偏离目标超过允许范围，系统应暂停自动下降并报警或进入低频修正模式，避免因传感器漂移导致过度移动。

这里的“休眠”指运动控制休眠：停止 STEP 脉冲、保持当前位置、等待下一次唤醒。默认不要通过 `MF` 释放电机电流，因为框篮是垂直负载，释放电机可能导致位置变化。只有在确认丝杆自锁可靠、框篮不会滑动，或增加机械制动后，才允许在维护模式中释放电机。

## UM244 控制信号接线

UM244 的 `PU/DR/MF` 输入高电平要求大于 4V，STM32 3.3V GPIO 不应直接驱动。推荐使用 5V 共阳接法，并用 NPN 三极管或光耦下拉输入负端。

推荐接法：

| UM244 端子 | 接法 |
|---|---|
| `PU+` | +5V |
| `DR+` | +5V |
| `MF+` | +5V |
| `PU-` | NPN 集电极，STM32 `STEP` 控制基极 |
| `DR-` | NPN 集电极，STM32 `DIR` 控制基极 |
| `MF-` | NPN 集电极，STM32 `MOTOR_RELEASE` 控制基极 |
| NPN 发射极 | STM32 GND |
| STM32 GND | 与 5V GND 共地 |

`MF` 为电机释放信号，低电平有效。默认状态下不释放电机，仅在维护、暂停释放或故障处理时使能释放。软件中需要明确处理该信号的有效逻辑。

## 限位开关接线

四个限位开关均为资料图中的 24V NPN 输出，触发后黑线输出低电平。限位器接线：

| 限位器线色 | 接法 |
|---|---|
| 棕色 | +24V |
| 蓝色 | 24V 0V |
| 黑色 | 24V 光耦隔离输入模块信号端 |

光耦输出到 STM32：

| 光耦输出 | 接法 |
|---|---|
| 输出 GND | STM32 GND |
| 输出信号 | STM32 GPIO |
| GPIO 上拉 | STM32 内部上拉或外接 10k 到 3.3V |

限位逻辑：

| 状态 | STM32 读数 |
|---|---|
| 未触发 | 高电平 `1` |
| 触发 | 低电平 `0` |

安全逻辑：

- 任意一个上限位触发，禁止继续上升
- 任意一个下限位触发，禁止继续下降
- 左右同方向限位状态不一致时立即停机报警，提示可能存在框篮倾斜、两侧不同步或限位安装偏差

## 有源蜂鸣器接线

新增蜂鸣器使用 `Materials/3-有源蜂鸣器` 中的低电平触发有源蜂鸣器模块。该模块原理图中已经包含 S8550 三极管，STM32 GPIO 只驱动模块 `I/O` 信号脚，不直接承载蜂鸣器工作电流。

推荐接线：

| 蜂鸣器模块 | STM32 最小系统板 |
|---|---|
| `VCC` | 3.3V |
| `GND` | GND |
| `I/O` | `PA5` |

控制逻辑：

| `PA5` 输出 | 蜂鸣器状态 |
|---|---|
| 高电平 `1` | 关闭 |
| 低电平 `0` | 鸣叫 |

`PA5` 初始化为推挽输出，默认置高电平，避免上电误鸣叫。由于该模块是 PNP 高边驱动结构，若 STM32 的 3.3V GPIO 直接接模块 `I/O`，模块 `VCC` 应接 3.3V。不要在直接驱动方案中把模块 `VCC` 接 5V，否则 STM32 的 3.3V 高电平可能无法可靠关闭蜂鸣器。若后续确实需要 5V 供电提高音量，应增加电平转换或改用独立三极管驱动。

## 电源与共地

电源结构：

| 电源 | 用途 |
|---|---|
| 220V AC 转 24V 5A | UM244 驱动器和 24V 限位器 |
| 24V 转 5V 降压 | 驱动器输入信号公共正端、可选外设 |
| 5V 转 3.3V 或核心板 3.3V | STM32、OLED、WF5805F、有源蜂鸣器模块 |

24V 5A 电源可以使用。5A 是电源可提供的最大电流能力，不会主动灌入驱动器。UM244 的电流上限由拨码和负载决定，调试时从 2.5A 运行电流开始。

驱动器功率地、5V 信号地、STM32 地需要建立明确参考关系。限位器 24V 输入侧通过光耦隔离，不直接把 24V 信号接入 STM32。

建议在 24V 电源输出端增加保险丝或自恢复保险丝，并给 STM32/传感器电源增加独立滤波，减少步进电机噪声影响 I2C。

## 断电与恢复策略

软件策略：

- 断电重启后默认保持电机不动
- 上电后读取三颗 WF5805F 和四个限位状态
- 从 Flash 读取目标曲线、运行天数、目标水深和估算位置
- 从 Flash 读取每日下降速度、今日已执行脉冲数、上次成功打盹移动时间和最近一次有效水深
- 断电期间错过的下降量不补偿，不做追赶运动
- 若传感器与限位状态正常，以上电时实测 `basket_depth_mm` 作为当前实际水深，从当前时刻继续按设定每日下降速度生成后续打盹位移
- 重启后的打盹调度重新从当前时刻开始计时，不把断电时间折算成待执行脉冲
- 若上电实测水深与断电前最近一次有效水深差异超过 2-3mm，进入暂停报警状态，等待人工确认
- 若传感器异常、限位异常或位置可信度不足，进入暂停报警状态，等待人工确认

不间断控制需要硬件支持。若要求断电期间也继续控制，需增加 24V UPS 或电池备份，并同时给 UM244、STM32、传感器供电。只有 STM32 备用电源而驱动器断电时，系统无法移动框篮。

## OLED 与按键功能

OLED 默认显示：

- 当前框篮实际水深
- 当前目标水深
- 运行天数
- 模式：自动、暂停、手动上升、手动下降
- 自动打盹模式参数：每日变浅量、单次脉冲数、下次唤醒倒计时
- 手动速度档位
- 今日已累计位移
- 限位和传感器状态
- 错误码和蜂鸣器静音状态

按键建议：

| 按键 | 功能 |
|---|---|
| `PB1` | 菜单/数值减/手动下降 |
| `PB11` | 菜单/数值加/手动上升 |
| `PB10` | 暂停/确认/报警静音 |
| `PA7` | 手动速度档位/打盹参数页面切换 |

手动移动时仍执行限位保护。自动模式下目标水深按设定曲线变化，默认允许误差为 ±1mm。

## 维护模式与人工操作

维护模式用于传感器校准、手动点动、速度测试、蜂鸣器静音确认和电机释放等人工维护操作。维护模式不能绕过限位保护，也不能绕过严重故障后直接恢复自动运行。

进入维护模式：

| 操作 | 行为 |
|---|---|
| 正常/暂停页面下长按 `PB10` 3 秒 | 进入维护模式确认页 |
| 确认页中短按 `PB10` | 确认进入维护模式 |
| 确认页中短按 `PA7` | 取消并返回上一页面 |

维护模式允许的操作：

| 功能 | 是否允许 | 说明 |
|---|---|---|
| 手动上升/下降 | 允许 | 长按移动，松手立即停止 |
| 手动速度档位切换 | 允许 | 默认从最低速开始 |
| 蜂鸣器静音 | 允许 | 只静音，不清除故障状态 |
| 压力传感器校准 | 允许 | 校准结果保存到 Flash |
| 电机释放 `MF` | 允许，但必须二次确认 | 用于维护；释放后不允许自动运动 |
| 忽略限位 | 不允许 | 任何模式都不能绕过上下限位 |
| 忽略左右限位不一致 | 不允许 | 该状态下禁止运动 |
| 忽略严重传感器故障并自动运行 | 不允许 | 只能维护检查，不能自动运行 |

退出维护模式：

| 操作 | 行为 |
|---|---|
| 维护模式下长按 `PB10` 3 秒 | 退出维护模式，回到暂停状态 |
| 触发严重故障 | 停止运动，保持维护模式并报警 |
| 重新上电 | 不自动恢复维护模式，先执行开机自检 |

维护模式安全底线：

- 上限位触发时，禁止继续上升。
- 下限位触发时，禁止继续下降。
- 左右同方向限位不一致时，禁止全部运动。
- 手动移动必须是长按动作，松手立即停止。
- 进入电机释放前，OLED 必须显示确认提示，蜂鸣器短鸣提示风险。
- 电机释放后，系统必须标记当前位置可信度降低；重新使能电机并人工确认后，才能退出维护模式。
- 维护模式下不执行自动打盹位移，不累计自动下降进度。

## 报警输出策略

报警同时通过 OLED、LED 和有源蜂鸣器表现。OLED 用于显示具体错误原因，LED 用于持续状态提示，蜂鸣器用于提醒操作者及时处理。

| 状态 | OLED | LED | 蜂鸣器 |
|---|---|---|---|
| 正常自动运行 | 显示水深、目标和打盹倒计时 | LED1 慢闪或常亮 | 关闭 |
| 暂停/手动模式 | 显示当前模式 | LED2 慢闪 | 关闭 |
| 一般警告 | 显示警告码和原因 | LED1/LED2 交替慢闪 | 短鸣 3 次后关闭 |
| 严重故障 | 显示故障码和人工确认提示 | LED1/LED2 快闪 | 间歇鸣叫，按 `PB10` 可静音 |

严重故障包括传感器连续读数失败、上下限位异常、左右同方向限位不一致、I2C 总线连续恢复失败、压力差明显超出物理范围。蜂鸣器静音只关闭声音，不清除故障状态；故障必须在原因消除并人工确认后才能恢复自动控制。

## 控制与安全行为

主控制目标是让 `basket_depth_mm` 跟随目标曲线。自动模式默认采用打盹式计划位移，每天累计让框篮相对水面上升 1mm，使框篮内水深缓慢变浅。控制器根据框篮实际水深、目标水深、当天剩余计划脉冲数和限位状态决定是否执行下一次微小位移：

- 框篮实际水深大于目标水深：框篮上升，使鱼可活动水深变浅
- 框篮实际水深小于目标水深：框篮下降，使鱼可活动水深变深
- 自动下降适应期内，不连续运行电机；只在打盹唤醒窗口内执行 `1 pulse` 或 `8 pulse` 的极小位移
- 误差在允许范围内：按每日计划继续打盹累加，不做额外追调
- 误差超过允许范围：停止计划下降，进入暂停报警或低频修正流程
- 每次位移后立即停止 STEP 脉冲，回到静止保持状态

异常处理：

- 任意传感器读数失败：停止自动移动，报警
- `P_basket - P_air` 为负或明显超出鱼缸物理范围：停止自动移动，报警
- 限位触发方向与运动方向冲突：停止对应方向运动
- 左右同方向限位不一致：停止全部运动，报警
- I2C 长时间无响应：重新初始化总线；连续失败后进入暂停报警

## 实现边界

本设计只固化硬件接线和系统行为。后续代码实现应优先添加在 `user/` 和 `Hardware/` 下，保持 Keil C 编译兼容，不修改 `Objects/`、`Listings/`、`DebugConfig/`、`Library/`、`start/`、`system/` 和 `*.uvguix` 文件。

代码和工程约束
用标准外设库，不要使用 HAL 库
代码风格：C 语言，注释清晰，易于理解
允许中断里做复杂逻辑，但尽量少用
命名风格默认但是要统一，函数名、变量名、宏定义
文件存放规则：每个模块一个 .c/.h 文件
我希望 Codex 主要只在Hardware目录下创建修改文件以及User目录下的main.c文件，其他目录严格禁止更改，可以在Hardware同目录下创建新的文件，但不要
修改已有文件，除非是修复bug或者添加必要的功能
代码必须能够编译通过，并且严格能在 STM32F103C8T6 上运行

后续实现可分为以下模块：

## 已知风险

- WF5805F 自制防水封装是系统最大硬件风险。封装必须保证水压可传递到传感器，同时电路不进水。
- 三颗绝对压力传感器需要统一标定零点和比例系数，否则会出现固定偏差。
- 两个电机并联一个驱动器时，电流分配和同步性不如两个驱动器独立控制。当前方案可用于原型验证，若出现不同步、丢步或温升异常，应升级为两个 UM244 驱动器共用 STEP/DIR。
- I2C 线缆进入水下环境后容易受电机噪声和线缆长度影响。框篮传感器已单独放在 `PB6/PB7` 总线，调试时仍需验证线缆长度、上拉阻值和屏蔽接地。
