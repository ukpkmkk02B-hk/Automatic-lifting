# 鱼缸框篮自动升降控制装置接线设计

日期：2026-05-04
状态：用户确认的暂定硬件接线方案

## 目标

本项目使用 STM32F103C8T6 控制鱼缸内框篮上下移动，使框篮内多鳍鱼实际可活动水深保持设定值，或按照设定曲线随时间缓慢变浅。控制对象是框篮相对鱼缸水面的高度，不是整体鱼缸水位。

框篮最大行程为 100mm。两个贯穿式步进电机同步驱动框篮两侧，丝杆导程为 2mm，丝杆长度为 250mm。水深控制允许误差目标为 ±1mm。

## 系统结构

系统由以下模块组成：

- STM32F103C8T6 最小系统板
- 0.96 寸 OLED 显示屏
- 三颗 WF5805F 压力传感器小板
- UM244 二相步进电机驱动器
- 两个 42HSC1409-250NE2 贯穿式丝杆步进电机
- 四个 24V NPN 限位开关
- 24V 5A 开关电源
- 5V 降压模块和 3.3V 供电
- 驱动器输入信号电平转换电路
- 24V 限位信号到 STM32 的光耦隔离输入电路

## 压力传感器方案

WF5805F 是绝对压力传感器，读数包含大气压。为达到 ±1mm 水深控制目标，系统使用三颗 WF5805F：

| 传感器 | 位置 | 作用 |
|---|---|---|
| `P_air` | 控制盒内，接触空气 | 大气压参考 |
| `P_tank` | 鱼缸底部固定位置 | 计算整体鱼缸水深并提供安全判断 |
| `P_basket` | 框篮底部，随框篮移动 | 计算框篮内实际可活动水深 |

水深计算使用压力差：

```text
basket_depth_mm = (P_basket - P_air) * 10.197
tank_depth_mm   = (P_tank   - P_air) * 10.197
```

其中压力单位为 hPa，`1 hPa` 约等于 `10.197 mmH2O`。

## WF5805F 两组 I2C 接线

不使用 I2C 多路复用器。三颗 WF5805F 分成两组 I2C：

| I2C 总线 | STM32 引脚 | 设备 | 地址选择 | I2C 7-bit 地址 |
|---|---|---|---|---|
| I2C-A | `PB8=SCL`, `PB9=SDA` | OLED | 固定 | OLED 常见地址 `0x3C`，现有代码使用写地址 `0x78` |
| I2C-A | `PB8=SCL`, `PB9=SDA` | `P_air` | `SDO/ADDR` 接 GND | `0x6C` |
| I2C-A | `PB8=SCL`, `PB9=SDA` | `P_tank` | `SDO/ADDR` 接 3.3V | `0x6D` |
| I2C-B | `PB6=SCL`, `PB7=SDA` | `P_basket` | `SDO/ADDR` 接 GND | `0x6C` |

每颗 WF5805F 小板接线：

| WF5805F 引脚 | 接法 |
|---|---|
| `VDD` | 3.3V |
| `GND` | GND |
| `SCL/SCLK` | 对应 I2C 总线 SCL |
| `SDA` | 对应 I2C 总线 SDA |
| `CSB` | 3.3V，固定 I2C 模式 |
| `SDO/ADDR` | 按地址接 GND 或 3.3V |
| `INT` | 暂不接，软件轮询读取 |
| `NC` | 不接 |

上拉电阻：

| 总线 | 上拉 |
|---|---|
| `PB8/PB9` | `SCL/SDA` 各 4.7k 上拉到 3.3V |
| `PB6/PB7` | `SCL/SDA` 各 4.7k 上拉到 3.3V |

每个传感器小板可预留 I2C 上拉焊盘，但同一总线上只焊一组 4.7k。若每块小板都必须焊上拉，建议使用 10k，避免并联后总上拉过强。

## WF5805F PCB 与防水封装要求

每块 WF5805F 小板必须包含：

- `VDD-GND` 旁路 100nF 电容，靠近芯片放置
- I2C 上拉电阻焊盘
- 四线接口：3.3V、GND、SCL、SDA
- 防水线缆应力释放
- 电路区域完全防水密封
- 压力敏感区域必须能接收到外部水压

封装必须避免把压力敏感结构完全刚性灌死。可采用柔性隔离膜、油腔或软胶膜等结构传递水压，同时防止水进入电路。空气参考传感器不下水，安装在控制盒内，保持与外界空气连通，避免盒内完全密封导致参考压力滞后。

## 步进电机与 UM244 驱动器

电机资料参数：

| 项目 | 数值 |
|---|---|
| 型号 | `42HSC1409-250NE2` |
| 步距角 | 1.8 度 |
| 额定电流 | 1.33A/相 |
| 额定电压 | 2.93V |
| 相电阻 | 2.2Ω |
| 相电感 | 3.5mH |
| 保持转矩 | ≥270mN.m |
| 丝杆导程 | 2mm |
| 标称步距 | 0.01mm/step |

UM244 供电：

| UM244 端子 | 接线 |
|---|---|
| `V+` | 24V 电源正 |
| `V-` | 24V 电源负 |
| `A+ A- B+ B-` | 接两个电机并联后的两相绕组 |

两个电机并联到同一个 UM244 驱动器输出。按资料线色，先按以下方式接线，并在低速低电流下确认方向：

| 电机线色 | 接线建议 |
|---|---|
| 红、绿 | 一相，接 `A+ / A-` |
| 黄、蓝 | 一相，接 `B+ / B-` |
| 两个电机 | 同色线并到同一个驱动器端子 |

若两个电机方向不一致，交换其中一个电机同一相的两根线，例如只交换该电机的 `A+ / A-`。

UM244 拨码建议：

| 项目 | 设置 |
|---|---|
| 运行电流 | 先设 2.5A：`SW1=ON`, `SW2=ON`, `SW3=OFF` |
| 细分/速度模式 | `SW4=OFF`，细分设置模式 |
| 细分 | 1600 pulse/rev：`SW5=OFF`, `SW6=OFF`, `SW7=ON`, `SW8=ON` |
| 位移换算 | 1600 pulse/rev ÷ 2mm = 800 pulse/mm |

若 2.5A 扭矩不足，可在确认温升和机械阻力正常后试 3.0A。不要按电源 5A 能力直接把驱动器电流拨到最大。

## UM244 控制信号接线

UM244 的 `PU/DR/MF` 输入高电平要求大于 4V，STM32 3.3V GPIO 不应直接驱动。推荐使用 5V 共阳接法，并用 NPN 三极管或光耦下拉输入负端。

推荐接法：

| UM244 端子 | 接法 |
|---|---|
| `PU+` | +5V |
| `DR+` | +5V |
| `MF+` | +5V |
| `PU-` | NPN 集电极，STM32 `STEP` 控制基极 |
| `DR-` | NPN 集电极，STM32 `DIR` 控制基极 |
| `MF-` | NPN 集电极，STM32 `MOTOR_RELEASE` 控制基极 |
| NPN 发射极 | STM32 GND |
| STM32 GND | 与 5V GND 共地 |

`MF` 为电机释放信号，低电平有效。默认状态下不释放电机，仅在维护、暂停释放或故障处理时使能释放。软件中需要明确处理该信号的有效逻辑。

## 限位开关接线

四个限位开关均为资料图中的 24V NPN 输出，触发后黑线输出低电平。限位器接线：

| 限位器线色 | 接法 |
|---|---|
| 棕色 | +24V |
| 蓝色 | 24V 0V |
| 黑色 | 24V 光耦隔离输入模块信号端 |

光耦输出到 STM32：

| 光耦输出 | 接法 |
|---|---|
| 输出 GND | STM32 GND |
| 输出信号 | STM32 GPIO |
| GPIO 上拉 | STM32 内部上拉或外接 10k 到 3.3V |

限位逻辑：

| 状态 | STM32 读数 |
|---|---|
| 未触发 | 高电平 `1` |
| 触发 | 低电平 `0` |

安全逻辑：

- 任意一个上限位触发，禁止继续上升
- 任意一个下限位触发，禁止继续下降
- 左右同方向限位状态不一致时立即停机报警，提示可能存在框篮倾斜、两侧不同步或限位安装偏差

## 电源与共地

电源结构：

| 电源 | 用途 |
|---|---|
| 220V AC 转 24V 5A | UM244 驱动器和 24V 限位器 |
| 24V 转 5V 降压 | 驱动器输入信号公共正端、可选外设 |
| 5V 转 3.3V 或核心板 3.3V | STM32、OLED、WF5805F |

24V 5A 电源可以使用。5A 是电源可提供的最大电流能力，不会主动灌入驱动器。UM244 的电流上限由拨码和负载决定，调试时从 2.5A 运行电流开始。

驱动器功率地、5V 信号地、STM32 地需要建立明确参考关系。限位器 24V 输入侧通过光耦隔离，不直接把 24V 信号接入 STM32。

建议在 24V 电源输出端增加保险丝或自恢复保险丝，并给 STM32/传感器电源增加独立滤波，减少步进电机噪声影响 I2C。

## 断电与恢复策略

软件策略：

- 断电重启后默认保持电机不动
- 上电后读取三颗 WF5805F 和四个限位状态
- 从 Flash 读取目标曲线、运行天数、目标水深和估算位置
- 若传感器与限位状态正常，恢复闭环控制
- 若传感器异常、限位异常或位置可信度不足，进入暂停报警状态，等待人工确认

不间断控制需要硬件支持。若要求断电期间也继续控制，需增加 24V UPS 或电池备份，并同时给 UM244、STM32、传感器供电。只有 STM32 备用电源而驱动器断电时，系统无法移动框篮。

## OLED 与按键功能

OLED 默认显示：

- 当前框篮实际水深
- 当前目标水深
- 运行天数
- 模式：自动、暂停、手动上升、手动下降
- 速度档位
- 限位和传感器状态

按键建议：

| 按键 | 功能 |
|---|---|
| `PB1` | 菜单/数值减/手动下降 |
| `PB11` | 菜单/数值加/手动上升 |
| `PB10` | 暂停/确认 |
| `PA7` | 速度档位/页面切换 |

手动移动时仍执行限位保护。自动模式下目标水深按设定曲线变化，默认允许误差为 ±1mm。

## 控制与安全行为

主控制目标是让 `basket_depth_mm` 跟随目标曲线。控制器根据框篮实际水深和目标水深的误差决定上升或下降：

- 框篮实际水深大于目标水深：框篮上升，使鱼可活动水深变浅
- 框篮实际水深小于目标水深：框篮下降，使鱼可活动水深变深
- 误差在 ±1mm 内：停止移动并保持

异常处理：

- 任意传感器读数失败：停止自动移动，报警
- `P_basket - P_air` 为负或明显超出鱼缸物理范围：停止自动移动，报警
- 限位触发方向与运动方向冲突：停止对应方向运动
- 左右同方向限位不一致：停止全部运动，报警
- I2C 长时间无响应：重新初始化总线；连续失败后进入暂停报警

## 已知风险

- WF5805F 自制防水封装是系统最大硬件风险。封装必须保证水压可传递到传感器，同时电路不进水。
- 三颗绝对压力传感器需要统一标定零点和比例系数，否则会出现固定偏差。
- 两个电机并联一个驱动器时，电流分配和同步性不如两个驱动器独立控制。当前方案可用于原型验证，若出现不同步、丢步或温升异常，应升级为两个 UM244 驱动器共用 STEP/DIR。
- I2C 线缆进入水下环境后容易受电机噪声和线缆长度影响。框篮传感器已单独放在 `PB6/PB7` 总线，调试时仍需验证线缆长度、上拉阻值和屏蔽接地。
