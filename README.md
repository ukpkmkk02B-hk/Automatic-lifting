# 鱼缸框篮自动升降控制固件

这是一个基于 **STM32F103C8T6** 和 **Keil5 标准外设库** 的鱼缸框篮自动升降控制项目。固件通过三颗 WF5805F 压力传感器测量空气参考、框篮水深和鱼缸整体水深，再驱动 UM244 步进电机驱动器缓慢调整框篮高度，让框篮内可活动水深按设定速率逐步变浅。

## 项目目标

- 控制对象是框篮高度，不直接控制整缸水位。
- 默认从 `100mm` 框篮水深逐步过渡到 `10mm`，默认变化速率为 `1mm/day`。
- 自动运动采用小脉冲“打盹式”位移，避免长时间极慢速连续运行。
- 断电期间不追补错过的位移，重新上电后优先保证安全和人工可确认性。

## 主要功能

- 三颗 WF5805F 独立软件 I2C 读取：`P_air`、`P_basket`、`P_tank`。
- 维护模式 `CAL AIR` 支持三传感器同空气零点校准，保存 `BAS/TNK` 相对 `AIR` 的固定偏移。
- 水深计算使用：
  - `basket_depth = ((P_basket - P_air) - zero_offset_basket) * 10.197`
  - `tank_depth = ((P_tank - P_air) - zero_offset_tank) * 10.197`
- UM244 同步驱动两台 42HSC1409-250NE2 贯穿式丝杆步进电机。
- 支持 0.96 寸 OLED 菜单显示、四键操作、参数设置、维护模式和调试读数。
- 支持上下限位保护、左右限位一致性检查、传感器失败检测、I2C 总线恢复失败报警、水位越界报警和蜂鸣器报警。

## 硬件平台

- MCU：STM32F103C8T6 最小系统板
- 工具链：Keil5 + STM32 Standard Peripheral Library
- 显示：0.96 寸 I2C OLED，软件 I2C `PB8/PB9`
- 压力传感器：三颗 WF5805F 2Bar 绝压传感器，固定地址 `0x6D`
- 电机驱动：UM244
- 执行机构：两台 42HSC1409-250NE2 贯穿式丝杆步进电机并联到同一个 UM244 输出
- 限位：四个 24V NPN 限位开关，经光耦隔离输入 STM32
- 报警：低电平触发有源蜂鸣器

三颗 WF5805F 地址相同，必须独占三条软件 I2C：

| 传感器     | 软件 I2C  | 用途         |
| ---------- | --------- | ------------ |
| `P_air`    | `PA1/PA2` | 空气参考压力 |
| `P_basket` | `PB6/PB7` | 框篮底部水深 |
| `P_tank`   | `PA8/PA9` | 鱼缸整体水深 |

## 上电调试顺序

1. 按 `bringup-checklist.md` 完成电源、OLED、按键、蜂鸣器检查。
2. 确认三颗 WF5805F 分别位于独立 I2C 总线，且 OLED 不与压力传感器共用总线。
3. 三颗传感器同处空气中执行维护菜单 `1 CAL AIR`，等待读数滤波稳定并确认 `BAS/TNK` 接近 `0.0mm`。
4. 将 `P_tank/P_basket` 放回水中，确认水深随浸入深度增加；实际水深恢复正常后再清除可能出现的 `TANK LOW` / `BASKET LOW`。
5. 验证四个限位、UM244 控制信号、电机方向、机械回零和 24 小时无鱼干运行。
6. 只有自动运行、安全报警和断电恢复行为都符合规格后，才允许放入鱼只。

## 安全说明

- 自动模式默认不释放电机，电机释放只允许在维护模式中二次确认。
- 限位保护在自动、手动和维护模式中都不能被绕过。
- 严重故障会停止自动运动；蜂鸣器静音只关闭声音，不清除故障状态。
- 空气校准期间三颗传感器都在空气中时，可能触发 `TANK LOW` / `BASKET LOW`。这是安全逻辑，不应屏蔽；应把水下传感器放回水中并确认实际水深恢复正常后，再人工清除故障。
- 本项目用于鱼只饲养环境，首次投运必须完成完整上电调试和不放鱼干运行验证。
