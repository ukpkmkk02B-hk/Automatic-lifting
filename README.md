# 鱼缸框篮自动升降控制固件

这是一个基于 **STM32F103C8T6** 和 **Keil5 标准外设库** 的鱼缸框篮自动升降控制项目。固件通过压力传感器测量水深，驱动步进电机缓慢调整框篮高度，让框篮内可活动水深按设定速度逐步变浅。

## 项目特点

- 使用 3 个 WF5805F 压力传感器分别测量空气参考、框篮水深和鱼缸水深。
- 使用 UM244 步进电机驱动器控制两台丝杆步进电机同步升降。
- 支持 0.96 寸 OLED 菜单显示、按键操作、参数设置和维护模式。
- 支持上下限位保护、传感器故障检测、I2C 恢复失败报警和蜂鸣器告警。
- 自动模式采用微小脉冲“打盹式”移动，避免长时间低速连续运行。
- 断电后不追补错过的移动，优先保证安全。

## 硬件平台

- MCU：STM32F103C8T6 最小系统板
- 工具链：Keil5 + STM32 Standard Peripheral Library
- 显示：0.96 寸 I2C OLED
- 传感器：WF5805F 绝压传感器
- 电机驱动：UM244
- 执行机构：42HSC1409-250NE2 丝杆步进电机
- 报警：低电平触发有源蜂鸣器

## 安全说明

本项目控制的是框篮高度，不控制整缸水位。自动运行前必须完成回零并确认限位、传感器和电机方向正确。严重故障会停止自动运动；蜂鸣器静音只关闭声音，不代表故障已经清除。
